## 二、修复策略

### 修复模式 A：`usd()` 包装函数（适用于返回数字的表达式）

参考 [KeyUsageView.vue](file:///Users/mac/sub2api/frontend/src/views/KeyUsageView.vue#L1156) 已建立的模式：

```typescript
// 在 <script setup> 中添加
import { useCurrencyStore } from '@/stores/currency'
const currencyStore = useCurrencyStore()
function usd(value: number | null | undefined): string {
  return currencyStore.formatAmount(value)
}
```

模板中将 `${{ value }}` 替换为 `{{ usd(value) }}`。

### 修复模式 B：`currencyStore.currencySymbol`（适用于返回字符串的本地格式化函数）

当本地 `formatXxx` 函数返回字符串（如 `toFixed(2)`）时：

```vue
{{ currencyStore.currencySymbol }}{{ formatCost(item.cost) }}
```

### 修复模式 C：工具函数（usagePricing.ts）

`utils/usagePricing.ts:48` 的 `$${formatted}` 需要改为使用 currencyStore。由于这是纯工具函数（非组件），需要让调用方传入 currencySymbol，或改为返回不带符号的纯数字让调用方包装。

**决策**：保持工具函数纯净，修改为接受 `symbol` 参数，调用方传入 `currencyStore.currencySymbol`。

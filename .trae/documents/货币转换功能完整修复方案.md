# 货币转换功能完整修复方案

## Context

货币转换功能当前存在严重 bug，导致功能实际上没有生效：

1. **currencyStore 从未被初始化** - `initFromInjectedConfig` 和 `initFromSettings` 都没有被调用，`exchangeRate` 永远为 0
2. **后端缺少设置项** - `default_display_currency` 和 `default_exchange_rate` 在后端完全不存在
3. **formatAmount 永远返回美元** - 由于 `exchangeRate <= 0`，即使切换到 CNY 也不转换
4. **30+ 前端页面使用硬编码** **`$`** - 不走 `currencyStore.formatAmount()`，无法响应货币切换

修复目标：让货币转换功能真正可用 — 管理员可配置汇率，用户切换货币后所有金额正确转换显示。保持业务逻辑不变，不增加新功能。

## 二、前端 Store 初始化

**文件**：`frontend/src/stores/app.ts`

## 四、前端页面修复（32 个文件）

### 修复模式

每个文件的标准步骤：

1. 添加 `import { useCurrencyStore } from '@/stores/currency'`
2. setup 中 `const currencyStore = useCurrencyStore()`
3. 添加包装函数（参考 KeyUsageView\.vue）：

   ```typescript
   function usd(value: number | null | undefined): string {
     if (value == null || value < 0) return '-'
     return currencyStore.formatAmount(value)
   }
   ```
4. 替换模板：`${{ formatCost(x) }}` → `{{ usd(x) }}`（删掉前导 `$`）
5. 替换 JS：`` `$${formatCost(value)}` `` → `currencyStore.formatAmount(value)`

## 六、风险和边界情况

1. **向后兼容**：旧部署升级后数据库缺少新 key，读取时安全回退到空/0（USD）
2. **汇率精度**：存储 8 位小数 float64，前端 6 位小数显示，足够覆盖常见汇率
3. **UI 闪烁**：`applySettings` 同步初始化，app mount 前完成，无闪烁
4. **安全**：汇率通过管理员 API 更新，前端用户只能读取不能修改
5. **AdminPaymentDashboardView 的 ¥**：需审查数据来源后决定是否替换

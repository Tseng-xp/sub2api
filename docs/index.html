TongYuan Aggregation API

Unified API gateway for multiple AI models

Quick Start

Use our API to access various AI models through a unified interface.

curl -X POST https://tongyuan-ai.cn/api/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-3.5-turbo",
    "messages": [{"role": "user", "content": "Hello"}]
  }'

API Endpoints

POST /api/v1/chat/completions

Create chat completion with the specified model.

POST /api/v1/completions

Create completion with the specified model.

GET /api/v1/models

List all available models.

Available Models

We support various models including GPT series, Claude, GLM, and more.
